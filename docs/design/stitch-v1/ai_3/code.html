school How to Verify Contract Addresses

  • looks_one Check Official Sources: Always get the CA (Contract Address) from the project's official Twitter bio, website, or established trackers like CoinGecko/CoinMarketCap.
  • looks_two Use ChainVigil Scanner: Paste the contract into our main scanner before interacting. We analyze the bytecode for malicious patterns regardless of the name.
  • looks_3 Don't Trust Names: Scammers can freely name their tokens exactly the same as legitimate ones (e.g., creating a fake 'USDT'). Only the contract address is unique.
