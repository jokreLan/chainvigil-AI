## 90 天战役

### 第 1 月：可信 + 试点名单

- [ ] 对外全面标明 mock/live  
- [ ] 锁定 10 个候选中文交易群（不求大，求真活跃）  
- [ ] 产出：1 页群主合作一页纸（权益：白标报告、高危提醒、分润预告）  
- [ ] 产出：每周 1 条「高危 CA 复盘」模板  

**出口指标**：≥3 群主口头同意试点；周内容 4 条。

### 第 2 月：真检测 + Bot 进群

- [ ] SOL/BNB 至少 1 条 live 证据路径上线  
- [ ] 正式 webhook secret + 频控  
- [ ] 5 个群完成 `/check` 试用  
- [ ] 收集误报清单（表格即可）

**出口指标**：周有效 `/check` ≥ 200（可按实际改）；误报有记录习惯。

### 第 3 月：VP 第二曲线试水

- [ ] 上线 1 个可感知权益（额外查询 or 监控 7 天）  
- [ ] 群主 growth 展示 pending/confirmed  
- [ ] Pro 定价试探（¥19–49/月 或等 U）文案 A/B 可人工  
- [ ] 复盘：哪类事件在拉新、哪类在刷

**出口指标**：有人问「怎么升级」或完成 ≥1 笔测试订阅意向。
